QuestionController — কীভাবে প্রশ্ন allow করে এবং priority ঠিক করে
Question queue — একসাথে ৩ worker জমা দিয়েছে, শুধু ১টাই যাবে
W016 Exam-এর সময় কোনটা? HIGH — exam কাল
W029 খরচের category কী? MEDIUM — same session
W068 কাল কয়টায় ঘুমিয়েছিলে? LOW — routine fill
QuestionController এর সিদ্ধান্ত প্রক্রিয়া
1
Worker → QuestionController-কে বলে: "আমার এই field-এর data দরকার, এই question করো।" সাথে priority hint দেয়: urgency, deadline, context।
2
QuestionController queue-এ add করে। Priority calculate করে: কাল deadline আছে? User কি এখন active? এই topic-এ preference NEVER আছে? সব check করে।
3
PreferenceManager দেখায় — এই worker বা topic block আছে? থাকলে queue থেকে সরিয়ে দেয়। NEVER state-এ থাকলে confirmation question-এ replace করে।
4
QuestionController highest priority question-টা select করে। Worker-এর context দেখে probable chips তৈরি করে। Response-এ question + chips attach করে পাঠায়।
5
User chip click করে বা type করে answer দেয়। QuestionController সেই answer টা সঠিক worker-এ route করে। Worker তার field fill করে task complete করে।
6
QuestionController queue-এর বাকি items দেখে — পরের response-এ পরের priority question পাঠাবে। User কখনো ২টা question একসাথে দেখবে না।
Data destination routing — answer কোথায় যাবে কে ঠিক করে
Worker নিজে route করে
Worker জানে তার data কোথায় যাবে। W029 (finance) জানে data যাবে finance.json-এ। W016 (exam) জানে data যাবে schedules.json-এ। এটাই default।
WorkerCollaborator route করে
একই data দুই worker-এর কাজে লাগে। Class routine — W005 (class alert) এবং W013 (sleep advisor) দুজনেই চায়। Collaborator একবার fetch করে দুজনকে দেয়।
StorageSyncManager route করে
যেকোনো Storage.set() call হলে SyncManager-এ event যায়। সে FileWriteQueue-তে add করে। একটা একটা করে write হয়। Race condition impossible।
